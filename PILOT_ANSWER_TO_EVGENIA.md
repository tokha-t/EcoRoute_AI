## Вариант для мессенджера

Евгения, добрый день! Спасибо, пилот на Байконуре очень интересен — готов участвовать.

Коротко по сути: EcoRoute прогнозирует заполненность контейнерных площадок и строит маршрут только по тем, которые действительно надо вывезти сегодня. Работает на данных, которые у оператора уже есть — графики вывоза, GPS мусоровозов, фото площадок. Датчики и закупка оборудования не нужны.

Что предлагаю по формату:

**Масштаб:** один сектор района — 150–300 контейнерных площадок, 1–2 мусоровоза. Плюс сопоставимый соседний сектор как контрольный, чтобы эффект был доказуемым.

**Этапы:**
- 1–14 сентября — сбор данных и замер текущих показателей (это и есть старт пилота)
- 15 сентября – 12 октября — теневой режим: система строит маршруты параллельно, реальные рейсы не меняются, сравниваем
- с 13 октября — работа по маршрутам системы, измерение эффекта
- декабрь — итоговый отчёт

**Что нужно от оператора (по Байконуру это ГорКомТранс):**
1. Реестр контейнерных площадок зоны с координатами
2. Действующие графики вывоза / маршрутные листы
3. Ответственное лицо с контактом

Желательно ещё GPS-треки за 4–8 недель и архив фото площадок, если водители их делают — но старт возможен и без них.

**Что даём:** ПО, панель диспетчера, обучение, еженедельные и итоговый отчёты. Для акимата бесплатно.

**Что измеряем:** километраж на смену, средняя заполненность при вывозе, число переполнений (не должно вырасти), нарушения максимального интервала (должно быть 0). Ориентир по экономии — 12–25% километража, это диапазон реальных внедрений; точную цифру назову после замера, раньше было бы нечестно.

Готов подключиться к встречам с акиматом и оператором в любое время. Полное описание пилота с ролями и списком данных могу прислать документом.

## Если попросит одну фразу для акима

> Система прогнозирует, какие контейнерные площадки нужно вывезти сегодня, и строит по ним кратчайший маршрут — чище дворы при меньшем пробеге. Работает на данных, которые у оператора уже есть, без закупки датчиков. Пилот на одном секторе Байконура, для города бесплатно, с измеримым результатом к декабрю.

## Если спросят «а что уже готово?»

Готов рабочий прототип: прогноз заполнения, приоритизация площадок, оптимизация маршрута с учётом вместимости мусоровоза и длительности смены, расчёт экономии, выгрузка маршрутных листов, карта для диспетчера. Есть модуль оценки заполненности по фотографии контейнера.

Сейчас всё это работает на смоделированных данных Астаны — реальные данные района встают на их место без переделки системы. Именно поэтому и нужен пилот.
