## Что нужно для старта (минимум)

### 1. Реестр контейнерных площадок зоны пилота — **критично**

Формат: приложенный шаблон `shablon_ploshadki.csv` (открывается в Excel).
Подойдёт **любая** ваша выгрузка — из ИС «Waste Management», Excel-таблица, даже список адресов. Шаблон нужен только чтобы не переспрашивать про столбцы.

| Столбец | Что это | Обязателен |
|---|---|---|
| `id_ploshadki` | Ваш внутренний номер площадки | да |
| `adres` | Адрес или ориентир | да |
| `shirota`, `dolgota` | Координаты (если есть) | желательно |
| `kolichestvo_konteynerov` | Сколько контейнеров на площадке | да |
| `obem_konteynera_l` | Объём одного контейнера в литрах (120/240/660/1100) | да |
| `tip_zastroyki` | multi-этажная / частный сектор / коммерция / смешанная | желательно |
| `grafik_vyvoza` | Дни недели или «ежедневно» | да |

Если координат нет — не проблема, определим по адресам.

### 2. Действующие графики вывоза или маршрутные листы — **критично**

За любой недавний период. Формат любой: Excel, скан, фото листа.
Это база для сравнения «как есть» → «как стало».

### 3. Ответственное лицо — **критично**

ФИО, должность, телефон/почта. Один человек, с которым решаются рабочие вопросы.

## Что сильно повысит точность (желательно)

### 4. GPS-треки мусоровозов зоны за 4–8 недель
Выгрузка из вашей системы мониторинга транспорта (Wialon или аналог) в любом формате: CSV, XLSX, GPX.
Нужные поля: номер/ID машины, дата-время, широта, долгота.
**Зачем:** восстановить реальную историю обслуживания площадок и посчитать текущий километраж — это база для доказательства экономии.

### 5. Фотофиксация площадок водителями, если ведётся
Архив фото «до/после» за любой период + привязка к площадке и времени.
**Зачем:** это готовая разметка для модели оценки заполненности. Самый ценный источник, если он у вас есть.
**Важно:** фото могут содержать лица людей и госномера — до обработки мы их обезличиваем (замыливаем), это фиксируется в соглашении о пилоте.

### 6. Данные весовой по рейсам за тот же период
Дата, машина, масса.
**Зачем:** калибровка расчёта объёмов.
